Данный репозиторий содержит HTML-структуру и первичные CSS-свойства для веб-сайта компании ГК "ФОРКЛИФТ", специализирующейся на продаже, аренде и обслуживании складской техники. <br>
Проект предназначен для разработки и поддержания пользовательского интерфейса корпоративного сайта.<br><br>

Основное содержимое:<br>
HTML-файлы:<br>
Структура страниц сайта, включая главную страницу, страницы услуг, каталога техники и контактов.<br>
CSS-файлы:<br>
  Первичные стили, обеспечивающие базовое оформление и дизайн сайта.<br>
  Поддержка адаптивного дизайна для корректного отображения на разных устройствах.<br><br>
Изображения:<br>
  Логотипы, иконки и другие графические элементы.<br><br>
Особенности проекта:<br>
  Использование современной семантической разметки HTML5.<br>
  Первичные CSS-стили для базового оформления (цветовая палитра, шрифты, отступы и выравнивание).<br>
  Подготовка структуры для дальнейшего добавления интерактивных элементов и интеграции с серверными технологиями.<br>
